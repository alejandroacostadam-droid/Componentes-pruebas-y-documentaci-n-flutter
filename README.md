# Proyecto GTA VI - Vice City

Esta rama integra tres componentes Flutter en una pantalla sencilla.

- ControlLuna: componente propio con seis fases y slider lunar.
- SelectorProtagonistas: paquete de la rama pablo-protagonistas.
- GtaSelectorCard: paquete de la rama Ramilla.

La aplicación de integración está en gta_vi_fan_companion. Sus dependencias apuntan a los paquetes independientes que hay en la raíz del repositorio.

Para ejecutarla, abre gta_vi_fan_companion, ejecuta flutter pub get y después flutter run. Las pruebas se ejecutan con flutter test en la app y dentro de cada paquete.
